# Employee Absenteeism Analysis

Understand the causes and cost of employee absence, and predict absence time in hours.

## Approach

- Exploratory analysis by reason, day and employee
- Linear Regression, Ridge and Lasso

## Results

R-squared between about 0.07 and 0.16 in the saved notebook output, so the value here is mainly in the analysis of causes.
